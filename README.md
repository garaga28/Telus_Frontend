## 🛠️ Tech Stack
- **Framework:** Next.js
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Netlify / Vercel

## ✨ Standout Features Implemented
1. **Custom Cursor:** A ring that follows the mouse and grows over links and buttons. Hidden on touch devices.
2. **Scroll-Triggered Reveals:** Sections and cards fade up with a stagger as they enter the viewport.
3. **Theme Switcher:** Animated dark/light mode toggle that remembers your choice.
4. **Scroll Progress Bar:** A smooth bar at the top showing how far you have scrolled.
